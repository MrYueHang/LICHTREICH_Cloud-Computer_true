# BookLab Agent Contract

## Canon

- A frozen canon is never overwritten by an agent.
- Editorial packages, chats and model outputs are proposal layers.
- Canon changes require a documented Decision Record.

## Required handoff

Every working branch returns:

1. `HANDOFF.md`
2. `FINDINGS.jsonl`
3. `PATCH_PROPOSAL.md` or `PATCH.diff`
4. `DECISIONS_REQUIRED.md`

## Evidence labels

- `[VERIFIED]`
- `[USER_MEMORY]`
- `[FICTION]`
- `[MODEL_INFERENCE]`
- `[POETIC_ANALOGY]`
- `[OPEN]`

## Privacy

Unpublished manuscripts, private memories, rights information and API keys are not committed to the public repository and are not sent to free third-party model fallbacks.
