# OFFENER KREIS — Distributed Production v16.1

## Versionslogik

- `v15.0`: belastbare Baseline, 54.267 Wörter / 24 Kapitel / 281 Seiten.
- `v16.0`: Editorial-Preproduction als wertvolle, aber unvollständige Vorschlagsschicht.
- `v16.1`: Context Reconciliation — Orte, Figuren, Objekte, Biografie, Wissenschaft, Qollektiv, Visualbestand, Publishing und Social.
- `v16.2`: Book Object Design Proof.
- `v17.0`: Release Candidate.

## Zuständigkeiten

- Hauptchat: Entscheidungen, Integration, Builds.
- Working: Ledgers und Patchvorschläge, keine Gesamtfassung.
- Research: Fakten, Recht, Wissenschaft, aktuelle Publishing-Anforderungen.
- Qollektiv: Entitäten, Rollen, CI, Rechte.
- Social/Publishing: Publish.OS, Quration, Kampagnen, Landingpage, KDP, Audio.
- Codex: BookLab-Code, Datenmodell, Tests, Imports; keine Literaturredaktion.

## Grundregel

Ergebnisse aus Randzweigen werden erst durch einen dokumentierten Decision Record Teil des Kanons. Private Manuskripte, Bilder, ZIPs und Erinnerungen bleiben lokal beziehungsweise in geschützten Speichern.
